# 核心价值定位：用户为什么要来我们这个站

确认日期：2026-10-05。状态：已确认的产品定位基石，所有功能取舍以本文档为准。

## 一句话定位

**GitHub 官方告诉你"什么在热"，我们告诉你"什么在真正崛起"——按领域、按自然日/周/月、用真实净增数字、用你的语言。**

英文名：GitRise（候选，域名待定）。核心标语：*See what's actually rising on GitHub.*

## GitHub 官方的五个真实痛点（我们的流量来源）

| # | GitHub 官网痛点 | 用户真实场景 | 我们的解法 |
|---|---|---|---|
| 1 | **Trending 是算法黑盒**：只显示一个列表，看不到具体涨了多少 star | 用户无法判断一个项目是真热还是被推荐位推上去的 | 所有榜单显示精确净增数字和增长率，口径公开 |
| 2 | **没有历史榜单**：昨天、上周、上月的 Trending 错过就永远看不到 | "上周那个很火的 AI 项目叫什么？" 无法回答 | 日/周/月榜单全部可回溯，永久存档 |
| 3 | **没有领域分类**：AI 框架、前端组件、游戏引擎混在一个榜里 | 前端工程师不关心 Kubernetes 工具，翻榜效率极低 | 10 个一级分类 + 细分标签，各领域独立榜单 |
| 4 | **只有英文**：描述、README 全是英文 | 中国（全球第二大开发者群体）及非英语用户有阅读门槛 | AI 生成中文摘要，原文保留并标注"自动翻译" |
| 5 | **没有增长率视角**：看不出"势头" | 100k star 老项目涨 200 ≠ 1k star 新项目涨 200 | 净增 + 增长率双指标，新项目爆发一眼可见 |

## 为什么这能带来流量

1. **搜索意图明确**："github trending weekly"、"github 趋势榜 中文"、"best new ai repos this month" 等词有持续搜索量，GitHub 官方无法满足。
2. **可索引页面多**：10 分类 × 3 周期 × 2 语言 × 历史存档 + 数万个项目详情页，天然 SEO 结构。
3. **回访动机**：榜单每天变，开发者有"每天看一眼"的习惯（Product Hunt / HN 模式）。
4. **分享动机**：项目作者上榜后会自发分享（"我们上了 XX 榜"），带来外链与社交流量。

## 变现路径（不注册、不付费、纯流量）

1. **Google AdSense**（主力）：内容型页面 + 全球流量，接入门槛低。需自定义域名，上线后申请。
2. **赞助位**（中期）：分类榜单顶部"Featured"位，面向开发者工具厂商（ MongoDB/Vercel 类公司常买此类广告）。
3. **不做的**：弹窗广告、诱导点击、内容农场——伤害回访率和 AdSense 审核。

## 功能取舍原则

- 一切功能必须服务于上表五个痛点之一，否则不做。
- 数字可信度是生命线：任何"覆盖不足/进行中"的数据必须明确标注，宁可少显示不可错显示（详见 classification-research.md 已确认口径）。
- 中英双语同等重要：英文面向全球，中文是最大的差异化增量市场。
